# پایان‌نامه اصلاح‌شده — راهنمای کامپایل

## فایل اصلی

- `thesis.tex` — کد کامل LaTeX پایان‌نامه پس از اعمال ۴ بند اصلاحیه استاد.
  همه تغییرات با کامنت `%% FIX` (همراه شماره بند، مثل `%% FIX (3-1): ...`)
  علامت‌گذاری شده‌اند تا قابل ردیابی باشند.
- `fonts/` — قلم‌های Noto Sans و Noto Sans Arabic **داخل پروژه**؛ نیازی به
  نصب فونت در سیستم نیست.
- `test-fa.tex` — فایل تست ۱۰ خطی برای بررسی سلامت محیط (باید فارسی نشان بدهد).

## روش پیشنهادی: Overleaf (راحت‌ترین، بدون نصب هیچ‌چیز)

۱. فایل `thesis-overleaf.zip` را از ریشه همین ریپو دانلود کنید.
۲. به سایت Overleaf بروید: **New Project ← Upload Project** و فایل زیپ را انتخاب کنید.
۳. از منوی گوشه بالا-چپ (**Menu**)، گزینه **Compiler** را روی **XeLaTeX** بگذارید.
۴. دکمه **Recompile** را بزنید. خروجی PDF با متن فارسی کامل نمایش داده می‌شود.

> نکته: سرویس‌های آنلاین تک‌فایلی (مثل texviewer) مناسب این پروژه نیستند،
> چون موتور XeLaTeX یا قلم فارسی ندارند و متن فارسی را سفید نشان می‌دهند.

## روش دوم: کامپایل محلی

- موتور **XeLaTeX** (حتماً XeLaTeX، نه pdfLaTeX) با توزیع کامل TeX Live یا MiKTeX
- بسته‌ها (در نصب کامل به‌صورت پیش‌فرض هستند):
  `tikz` ،`algorithm` ،`algorithmic` ،`listings` ،`graphicx`

```bash
cd thesis
xelatex thesis.tex
xelatex thesis.tex   # اجرای دوم برای فهرست‌ها و ارجاع‌ها
```

خروجی: `thesis.pdf`

## چند نکته مهم

۱. **شماتیک‌های رابط کاربری** (شکل‌های ۴-۴ و ۴-۵) عمداً با TikZ و با عنوان
   «شماتیک» رسم شده‌اند. پیش از چاپ نهایی، تصویر واقعی سامانه با داده
   آزمایشی را جایگزین کنید؛ الگوی آماده `includegraphics` به‌صورت کامنت
   زیر شکل داشبورد گذاشته شده است.
۲. **تاریخ‌ها** (شهریور ۱۴۰۵ / ۲۵ شهریور ۱۴۰۵ / September 2026) عیناً از
   نسخه نویسنده حفظ شده‌اند؛ اگر تاریخ دفاع تغییر کرد فقط همان سه‌جا را
   اصلاح کنید.
۳. **اعداد ارزیابی** (جدول‌های کارایی و امنیت) عیناً از نسخه نویسنده حفظ و
   با پروتکل، حدود اعتبار و نمودار تصویری قاب‌بندی شده‌اند.
۴. شماره شکل‌ها/جدول‌ها/الگوریتم‌ها خودکار است (`فصل-ردیف` با ارقام فارسی)؛
   اگر شکلی اضافه/حذف کردید فقط کافی است دو بار کامپایل کنید.
